# GAMEPLAY.md

## Base release gameplay

The base release should provide the recognizable round-based loop:

1. Enter menu.
2. Start offline play or create/join a local lobby.
3. Load a map.
4. Intermission/countdown.
5. Select or randomize a disaster according to server settings.
6. Run the disaster simulation.
7. Track player survival/death.
8. End round.
9. Show results.
10. Return to lobby/intermission.

## Base release UI

Required before post-release updates:

- main menu
- loading screen
- lobby screen
- server/lobby settings
- player list
- round HUD
- results screen
- pause/options screen

## Updates

Cosmetics, unlockables, and gear belong to the update track and must be implemented through extension points that do not complicate the base game.
